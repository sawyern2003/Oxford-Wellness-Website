# Blog Image Credits

All blog hero images should be sourced from Unsplash (unsplash.com) or Pexels (pexels.com), which provide free commercial use licences.

## Image Requirements
- Natural light, calm aesthetic
- Women aged 40-65 where people are shown
- Oxford cityscapes, interior spaces, or botanical textures where appropriate
- No needles, clinical procedures, before/after shots, or graphic content
- Convert to WebP format
- Hero images: ~1600px wide, under 200KB
- Card images: ~800px wide, under 150KB
- Include width and height attributes
- Use descriptive alt text

## Sourcing Instructions

1. Search Unsplash/Pexels for appropriate images matching each description
2. Download high-resolution versions
3. Convert to WebP using tools like Squoosh or cwebp
4. Optimize for web (target sizes noted above)
5. Add photographer credit to this file
6. Upload to public directory
